# Guia para colaboradores (CMS)

A versão partilhável deste guia está numa **página web privada** (não aparece no menu do site):

**https://portonaomonogamico.com/guia-colaboradores**

- Endereço local / relativo: `/guia-colaboradores`
- Não é indexada por motores de busca (`noindex`)
- Código da página: `src/pages/guia-colaboradores.astro`

Envia esse link aos colaboradores depois de os convidares no GitHub (Write / collaborator no repositório).
